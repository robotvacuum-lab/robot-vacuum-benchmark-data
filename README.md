# Robot Vacuum Empirical Benchmark Dataset

Standardized testing protocols and performance datasets maintained by [RobotVacuum Lab](https://robotvacuumlab.com/).

## Overview
This repository contains empirical hardware test metrics collected from consumer robotic vacuum cleaners in Sheridan, Wyoming. 

### Tested Parameters
- **Suction Power & Retention**: Airflow measurements and particulate pickup efficiency across hardwood and carpet floors.
- **LiDAR Navigation Accuracy**: 3D structured light mapping latency and obstacle avoidance clearance rates.
- **Acoustic Noise Ratings**: Calibrated sound pressure levels (dBA) recorded under standard and maximum operating modes.

For interactive performance charts, methodology whitepapers, and the complete lab database, visit the [Best Robot
Vacuum and Mop](https://robotvacuumlab.com/).
